SprigCast for Linux: test build
===============================

This is an early test build. SprigCast on Linux starts, draws blooms from images, text, video files and web
pages, records, and streams with the CPU encoder (or an NVIDIA card's encoder).

Not on Linux yet: microphone and desktop sound, screen and window capture, the virtual camera, global
hotkeys and in-app updates. They are being built.

Start it
--------
1. Unpack this folder anywhere you like.
2. Run the file named SprigCast inside it (double-click, or ./SprigCast in a terminal).

Stream keys are kept in your desktop's password store (GNOME Keyring or KWallet).

Send us what you find
---------------------
In SprigCast: Help, Export report. It saves one zip with your logs (stream keys and personal
details are scrubbed). Share it in the SprigCast Discord: https://discord.gg/fgMD33XrhM

Logs live in ~/.local/state/SprigCast/Logs.
