# RNNoise model

`voice.rnnn` is the "somnolent-hogwash" model (speech, with recording noise) from
https://github.com/GregorR/rnnoise-models (2018-09-01), used by Noise Suppression's RNNoise method through
FFmpeg's `arnndn` filter. Its author states the models are not creative work and not subject to copyright.
